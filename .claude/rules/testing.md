# Rule: smoke tests + матрица для проверки

## TL;DR

После любого изменения в `src/templates/declaration-eaeu-light/compose.ts`:

```powershell
cd C:\Users\Admin\Documents\GitHub\global-test
npx tsx scripts/test-dict-cases.ts        # 39 кейсов словаря — должны быть 39/39
npx tsx scripts/test-tnved.ts             # 11 кейсов ТН ВЭД — 11/11
npx tsx scripts/test-gosts.ts             # 4 кейса ГОСТ-классификации
npx tsx scripts/test-compose-full.ts      # сводка по памятке P15 + типичным случаям
npx tsc --noEmit                          # TypeScript clean
```

Если какой-то тест падает — **не двигаться дальше**. Исправить регрессию, потом продолжать.

## Что покрывают тесты

### `test-dict-cases.ts` — 39 кейсов
Все составы из скорректированного словаря `docs/composition-dictionary.docx`:
- Чистые материалы (100%): хлопок, лён, шерсть, шёлк, полиэстер, вискоза и т.д.
- Натуральный с примесью: «хлопчатобумажная с вложением синтетических нитей» и т.п.
- Смеси натуральных: «полульняная», «полушерстяная» по правилам приоритета
- Синтетико-доминантные: «из ткани из сочетания …»

Проверяет: правильное формирование `fabricPhrase` (без скобок с %).

### `test-tnved.ts` — 11 кейсов с явными ожидаемыми кодами
Включая edge-кейсы:
- Платья швейные синтетика → 6204430000
- Брюки женские трикотаж шерсть → **6104610001** (EAEU override)
- Шорты женские трикотаж шерсть → **6104610009** (EAEU override)
- Бриджи женские трикотаж шерсть → 6104610001 (модель → база «брюки»)
- Костюмы / Пиджаки / Куртки / Платья / Юбки / Брюки разных полов и материалов

### `test-gosts.ts` — 4 сценария
- Только блузки → ГОСТ 25294

- Блузки + пиджак → оба

### `test-compose-full.ts` — 6 крупных сценариев
- Памятка P15 (детское бельё, 3 разных состава) — структура должна совпасть

### `test-assortment.ts` — 5 кейсов агрегации моделей
- Сарафан → «платья, в том числе модель «сарафан»»

## Полные матрицы (для визуальной проверки)

### `docs/test-matrix.docx` — 66 кейсов выборочно


### `docs/test-matrix-full.docx` — 505 кейсов
Полная сетка: ~32 типа изделий × 7 материалов × валидные комбинации gender×production
+ 10 мульти-продукт + 6 граничных кейсов + 5 редких материалов. Landscape A3.
Генерируется:

### `docs/composition-dictionary.docx` — 39 составов
Словарь «состав → формулировка ткани». Не для тестирования логики, а для оператора
как справочник. Генерируется:
```powershell

```

## Что НЕ покрыто (известные пробелы)

- ГОСТы на бельевые/корсетные изделия (1-й слой) — пока выводится `—`. Добавить ГОСТ когда подтвердится номер.
- EAEU last-4 для большинства кодов — дефолт `0000`. Конкретные исключения в `EAEU_LAST_4_OVERRIDES`. Пополняется по мере получения подтверждений от таможни.
- Трикотажные ткани под отдельным ГОСТ 31228 — сейчас классифицируются как ГОСТ 25294 (платьево-блузочный), что технически не точно для свитеров/толстовок.

## Когда упало

1. Запусти каждый смок-тест отдельно — найди первый падающий.
2. Прочитай ожидаемое значение и сравни с актуальным — это покажет ровно что сломалось.
3. Если регрессия — обычно последнее изменение `compose.ts`. Сделай git diff и проверь логику.
4. Если новый кейс корректнее старого ожидания → обнови ожидание в тесте + обнови `.claude/rules/decl-format.md`.
